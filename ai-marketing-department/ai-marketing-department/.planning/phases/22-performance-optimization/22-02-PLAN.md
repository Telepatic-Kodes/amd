# Plan 22-02: Vercel Analytics + Speed Insights + Mobile Viewport + Keyboard Types

## Goal
Add production observability (Vercel Analytics + Speed Insights), fix mobile viewport issues, and add proper keyboard types to form inputs.

## Tasks

### T1: Install and configure Vercel Analytics + Speed Insights
- `npm install @vercel/analytics @vercel/speed-insights`
- Add `<Analytics />` and `<SpeedInsights />` to layout.tsx
- These are tree-shaken in dev, only active in Vercel production

### T2: Add inputMode attributes to form inputs
- Search all `<input type="text">` and `<textarea>` for opportunities
- Add `inputMode="email"` for email fields
- Add `inputMode="url"` for URL fields
- Add `inputMode="numeric"` for number fields
- Add `inputMode="search"` for search fields

### T3: Mobile viewport testing fixes
- Audit at 375px (iPhone SE), 393px (iPhone 14), 768px (iPad)
- Fix any horizontal overflow issues
- Verify 44x44px minimum touch targets
- Fix any text truncation issues

## Verification
- `npm run build` succeeds
- All existing tests pass
- Dev server shows Analytics/SpeedInsights loading in prod mode
