# Plan 22-01: Code Splitting + Bundle Analysis + Image Optimization

## Goal
Reduce initial bundle size by 40-60% through dynamic imports of heavy components, install bundle analyzer, add viewport metadata, and optimize images.

## Context
- Zero dynamic imports currently — every component loads synchronously
- Heavy deps: recharts (~8MB), @tiptap (~7MB), framer-motion (~5MB), pdf-parse (~21MB)
- Chart components (BarChart, AreaChart, LineChart, DonutChart) import recharts directly
- Modals (EditContentModal, GenerateContentModal, QuickExecuteModal) are conditionally rendered but always bundled

- No viewport metadata in layout.tsx
- No @next/bundle-analyzer installed
