<task name="create-rich-text-editor-component">
  <description>Create an isolated, reusable RichTextEditor component using TipTap with core formatting support</description>
  <steps>
    1. Create file: `components/content/RichTextEditor.tsx`
    2. Mark as client component with `"use client"`
    3. Define the component interface:
       ```typescript
       interface RichTextEditorProps {
         content: string;              // Initial content (plain text or HTML)
         onChange: (html: string) => void;  // Callback with HTML content
         onPlainTextChange?: (text: string) => void;  // Optional plain text callback
         placeholder?: string;
         minHeight?: string;           // Default "200px"
         maxHeight?: string;           // Default "400px"
         editable?: boolean;           // Default true
         className?: string;
       }
       ```
    4. Initialize TipTap editor with useEditor hook:
       ```typescript
       const editor = useEditor({
         extensions: [
           StarterKit.configure({
             heading: { levels: [1, 2, 3] },
             bulletList: {},
             orderedList: {},
             codeBlock: {},
             blockquote: {},
             horizontalRule: {},
           }),
           Link.configure({
             openOnClick: false,
             HTMLAttributes: { class: 'text-indigo-400 underline hover:text-indigo-300' },
           }),
           Placeholder.configure({
             placeholder: placeholder || 'Start writing...',
           }),
           CharacterCount,
         ],
         content: content,
         editable: editable,
         onUpdate: ({ editor }) => {
           onChange(editor.getHTML());
           onPlainTextChange?.(editor.getText());
         },
         editorProps: {
           attributes: {
             class: 'prose prose-invert prose-sm max-w-none focus:outline-none min-h-[200px] px-3 py-2',
           },
         },
       });
       ```
    5. Keyboard shortcuts are included via StarterKit by default:
       - Ctrl+B: Bold
       - Ctrl+I: Italic
       - Ctrl+Shift+X: Strikethrough
       - Ctrl+E: Code
       - Ctrl+Shift+7: Ordered list
       - Ctrl+Shift+8: Bullet list
       - Ctrl+Alt+1/2/3: Headings
    6. Build a minimal fixed toolbar with formatting buttons:
       ```typescript
       const ToolbarButton = ({ onClick, isActive, children, title }) => (
         <button
           type="button"
           onClick={onClick}
           title={title}
           className={cn(
             "p-1.5 rounded text-xs transition-colors",
             isActive
               ? "bg-indigo-500/20 text-indigo-400"
               : "text-zinc-400 hover:text-white hover:bg-zinc-800"
           )}
         >
           {children}
         </button>
       );
       ```
    7. Toolbar buttons (using Lucide icons):
       - Bold (Bold icon)
       - Italic (Italic icon)
       - Strikethrough (Strikethrough icon)
       - Code (Code icon)
       - H1, H2, H3 (Heading icon + number)
       - Bullet List (List icon)
       - Ordered List (ListOrdered icon)
       - Blockquote (Quote icon)
       - Link (Link icon) - opens simple prompt for URL
       - Horizontal Rule (Minus icon)
    8. Wrap editor in a container matching existing design system:
       ```
       rounded-lg border border-zinc-800 bg-zinc-950/50 overflow-hidden
       ```
    9. Add toolbar separator between button groups (formatting | structure | block)
    10. Add useCallback for onChange to prevent unnecessary re-renders
    11. Handle the content initialization edge case:
        - If content is plain text (no HTML tags), wrap in <p> tags
        - If content is HTML, use as-is
        - Detect via regex: /<[a-z][\s\S]*>/i
    12. Add cleanup: return editor?.destroy() in useEffect cleanup
  </steps>
  <acceptance>
