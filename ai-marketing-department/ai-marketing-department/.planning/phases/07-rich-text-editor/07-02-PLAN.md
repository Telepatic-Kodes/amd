## Plan 07-02: Toolbar Polish & BubbleMenu

**Objective:** Extract toolbar into a dedicated component, add a floating BubbleMenu for inline formatting, and create a proper link insertion dialog.

**Estimated Effort:** 6-8 hours
**Risk Level:** Low

---

### Tasks

<task name="extract-editor-toolbar">
  <description>Extract the toolbar from RichTextEditor into a dedicated EditorToolbar component with improved UX</description>
  <steps>
    1. Create file: `components/content/EditorToolbar.tsx`
    2. Mark as `"use client"`
    3. Define interface:
       ```typescript
       interface EditorToolbarProps {
         editor: Editor | null;
         onLinkClick: () => void;
       }
       ```
    4. Move all toolbar rendering logic from RichTextEditor into this component
    5. Organize buttons into logical groups with visual separators:
       - **Text formatting:** Bold, Italic, Strikethrough, Code
       - **Headings:** H1, H2, H3
       - **Lists & Structure:** Bullet List, Ordered List, Blockquote
       - **Insert:** Link, Horizontal Rule
       - **Undo/Redo:** Undo, Redo (using Undo2, Redo2 from Lucide)
    6. Add separator component between groups:
       ```typescript
       const ToolbarSeparator = () => (
         <div className="w-px h-5 bg-zinc-700 mx-1" />
       );
       ```
    7. Style the toolbar container:
       ```
       flex items-center gap-0.5 flex-wrap px-2 py-1.5 border-b border-zinc-800 bg-zinc-900/50
       ```
    8. Add tooltips to each button using the `title` attribute:
       - "Bold (Ctrl+B)"
       - "Italic (Ctrl+I)"
       - "Heading 1 (Ctrl+Alt+1)"
       - etc.
    9. Handle disabled state when editor is null or not editable
    10. Update RichTextEditor to import and use EditorToolbar
  </steps>
  <acceptance>
    - EditorToolbar renders as a standalone component
    - Buttons grouped logically with separators
    - Undo/Redo buttons functional
    - Tooltips show keyboard shortcuts
    - Disabled state handled when editor is null
    - Visual styling consistent with zinc/indigo theme
  </acceptance>
</task>

<task name="add-bubble-menu">
  <description>Add a floating BubbleMenu that appears when text is selected, showing inline formatting options</description>
  <steps>
    1. Install BubbleMenu extension (if not included in starter-kit):
       ```
       npm install @tiptap/extension-bubble-menu
       ```
       Note: @tiptap/react includes BubbleMenu component, so this may already be available.
    2. Create file: `components/content/BubbleMenuBar.tsx`
    3. Mark as `"use client"`
    4. Define interface:
       ```typescript
       interface BubbleMenuBarProps {
         editor: Editor;
       }
       ```
    5. Import BubbleMenu from @tiptap/react:
       ```typescript
       import { BubbleMenu } from '@tiptap/react';
       ```
    6. Render a compact floating toolbar with inline formatting:
       ```typescript
       <BubbleMenu
         editor={editor}
         tippyOptions={{
           duration: 150,
           placement: 'top',
         }}
         className="flex items-center gap-0.5 rounded-lg border border-zinc-700 bg-zinc-800 px-1.5 py-1 shadow-xl"
       >
         <BubbleButton
           onClick={() => editor.chain().focus().toggleBold().run()}
           isActive={editor.isActive('bold')}
           title="Bold"
         >
           <Bold className="h-3.5 w-3.5" />
         </BubbleButton>
         <BubbleButton ... italic />
         <BubbleButton ... strikethrough />
         <BubbleSeparator />
         <BubbleButton ... link />
         <BubbleButton ... code />
       </BubbleMenu>
       ```
    7. Style BubbleMenu buttons slightly smaller than toolbar buttons:
       ```typescript
       const BubbleButton = ({ onClick, isActive, children, title }) => (
         <button
           type="button"
           onClick={onClick}
           title={title}
           className={cn(
             "p-1 rounded text-xs transition-colors",
             isActive
               ? "bg-indigo-500/30 text-indigo-300"
               : "text-zinc-300 hover:text-white hover:bg-zinc-700"
           )}
         >
           {children}
         </button>
       );
       ```
    8. Only show BubbleMenu for text selections (not for empty selections or node selections)
    9. Add the BubbleMenuBar to RichTextEditor, rendered inside the EditorContent wrapper:
       ```typescript
       {editor && <BubbleMenuBar editor={editor} />}
       <EditorContent editor={editor} />
       ```
    10. Test that BubbleMenu appears on text selection and disappears on deselection
    11. Ensure BubbleMenu does not conflict with the fixed toolbar
  </steps>
  <acceptance>
    - BubbleMenu appears when text is selected
    - BubbleMenu disappears when selection is cleared
    - Inline formatting buttons (bold, italic, strike, code, link) work from BubbleMenu
    - BubbleMenu has dark theme styling (zinc-800 background)
    - BubbleMenu does not interfere with fixed toolbar
    - Smooth animation on appear/disappear (150ms)
    - Positioned above the selection
  </acceptance>
</task>

<task name="create-link-dialog">
  <description>Create a proper link insertion/editing dialog instead of window.prompt</description>
  <steps>
    1. Create file: `components/content/LinkDialog.tsx`
    2. Mark as `"use client"`
    3. Define interface:
       ```typescript
       interface LinkDialogProps {
         isOpen: boolean;
         onClose: () => void;
         onSubmit: (url: string) => void;
         initialUrl?: string;
       }
       ```
    4. Build a small inline popover/dialog:
       ```typescript
       - Text input for URL with placeholder "https://..."
       - "Apply" button (indigo-500)
       - "Remove" button (only shown when editing existing link)
       - "Cancel" button or click-outside to close
       ```
    5. Style to match existing modal design:
       ```
       bg-zinc-800 border border-zinc-700 rounded-lg shadow-xl p-3
       ```
    6. Add URL validation:
       - Must start with http:// or https:// or mailto:
       - Show validation error in red-400 text
    7. Auto-focus the URL input when dialog opens
    8. Handle Enter key to submit, Escape to cancel
    9. Position the dialog near the toolbar link button or near the selection
    10. Update EditorToolbar link button to open LinkDialog:
        ```typescript
        const [showLinkDialog, setShowLinkDialog] = useState(false);
        // On link button click:
        const currentUrl = editor.getAttributes('link').href || '';
        setShowLinkDialog(true);
        ```
    11. Update BubbleMenuBar link button similarly
    12. On submit:
        ```typescript
        if (url) {
          editor.chain().focus().extendMarkRange('link').setLink({ href: url }).run();
        }
        ```
    13. On remove:
        ```typescript
        editor.chain().focus().extendMarkRange('link').unsetLink().run();
        ```
  </steps>
  <acceptance>
    - Link dialog opens when clicking link button in toolbar or BubbleMenu
    - URL input auto-focuses
    - URL validation works (must be valid URL)
    - Enter submits, Escape cancels
    - Link is applied to selected text
    - Existing links can be edited (dialog pre-fills URL)
    - Existing links can be removed
    - Dialog styling matches dark theme
  </acceptance>
</task>
