- `text-stone-900` → `text-[var(--text-primary)]`
- `text-stone-800` → `text-[var(--text-primary)]`
- `text-stone-700` → `text-[var(--text-secondary)]`
- `text-stone-600` → `text-[var(--text-secondary)]`
- `text-stone-500` → `text-[var(--text-tertiary)]`
- `text-stone-400` → `text-[var(--text-tertiary)]`
- `text-orange-600` → `text-[var(--accent)]`
- `text-gray-*` → map to equivalent --text-* variable

Borders:
- `border-stone-200` → `border-[var(--border)]`
- `border-stone-100` → `border-[var(--border)]`
- `border-stone-300` → `border-[var(--border-hover)]`
- `border-gray-200` → `border-[var(--border)]`

Status/badge colors:
- `bg-blue-50` → `bg-[var(--badge-blue-bg)]` / `text-blue-*` → `text-[var(--badge-blue-text)]`
- `bg-green-50` → `bg-[var(--badge-green-bg)]` / `text-green-*` → `text-[var(--badge-green-text)]`
- `bg-red-50` → `bg-[var(--badge-red-bg)]` / `text-red-*` → `text-[var(--badge-red-text)]`

- `bg-purple-50` → `bg-[var(--badge-purple-bg)]` / `text-purple-*` → `text-[var(--badge-purple-text)]`

Hover states:
- `hover:bg-stone-50` → `hover:bg-[var(--surface-1)]`
- `hover:bg-stone-100` → `hover:bg-[var(--surface-2)]`
