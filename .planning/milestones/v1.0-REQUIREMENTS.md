# Requirements: AMD UX Simplification

**Defined:** 2026-01-30
**Core Value:** Non-technical users can manage complete marketing department in minutes

## v1 Requirements

### Phase 1-4: Foundation (Completed ✓)

- [x] **NAV-01**: Sidebar navigation reduced to 4 main items (Inicio, Contenido, Resultados, Configuración)
- [x] **NAV-02**: All navigation labels in Spanish, with descriptive tooltips
- [x] **ONBOARD-01**: Onboarding flow reduced from 6 to 3 steps
- [x] **ONBOARD-02**: Setup time reduced to <2 minutes with auto-configured departments
- [x] **FEEDS-01**: Feed templates system with 10 industry bundles available
- [x] **FEEDS-02**: 1-click feed setup from pre-configured templates
- [x] **LANG-01**: 100% Spanish translation of all UI labels
- [x] **HOME-01**: Home page displays personalized greeting
- [x] **HOME-02**: Home page shows 3 metric cards (more spacious than before)
- [x] **HOME-03**: Feed Health Summary widget visible on home page
- [x] **RESULT-01**: Results page shows 3 KPIs (Views, Clicks, Engagement)
- [x] **RESULT-02**: Results page includes 7-day trend chart
- [x] **RESULT-03**: Top 5 performing content visible on results page
- [x] **HEALTH-01**: Feed health report page (/feeds/health) shows detailed metrics

### Phase 5: Design Polish (Completed ✓)

- [x] **DESIGN-01**: Increase global spacing (gaps 32px → 48px)
- [x] **DESIGN-02**: Larger typography throughout (headers, body text)
- [x] **DESIGN-03**: Padding increased on cards (16px → 24px)
- [x] **DESIGN-04**: Buttons more prominent with gradients
- [x] **DESIGN-05**: Progressive disclosure (filters, advanced options collapsed by default)
- [x] **MOBILE-01**: Responsive design for mobile screens (375px width)
- [x] **MOBILE-02**: Touch targets minimum 44x44px (WCAG standard)
- [x] **MOBILE-03**: Bottom navigation bar visible on mobile (tab-style)
- [x] **MOBILE-04**: Single-column card layout on mobile
- [x] **MOBILE-05**: Readable fonts on small screens (min 16px for body)

### Phase 6: Product Tour (Completed ✓)

- [x] **TOUR-01**: Interactive 7-step product tour for new users
- [x] **TOUR-02**: Tour shows key features with contextual tooltips
- [x] **TOUR-03**: Users can skip tour and return later
- [x] **TOUR-04**: Tour only displays for first-time users
- [x] **TOUR-05**: Tour accessible from help/onboarding section

### Phase 7: Rich Text Editor (Completed ✓)

- [x] **EDITOR-01**: WYSIWYG editor with formatting (bold, italic, headers, lists, links, code)
- [x] **EDITOR-02**: Real-time preview alongside editor
- [x] **EDITOR-03**: Keyboard shortcuts (Ctrl+B, Ctrl+I, etc.)
- [x] **EDITOR-04**: Content validation and character count
- [x] **EDITOR-05**: Export to plain text and HTML

### Phase 8: File Upload (Completed ✓)

- [x] **FILE-01**: Drag-drop file upload for PDF, DOCX, TXT
- [x] **FILE-02**: Content extraction and parsing
- [x] **FILE-03**: Preview before import
- [x] **FILE-04**: Error handling for unsupported formats
- [x] **FILE-05**: File size validation

- **ANALYT-03**: Feature usage analytics

## Out of Scope

| Feature | Reason |
|---------|--------|
| Real-time collaboration | High complexity, not core to simplicity value |
| Advanced data export | Feature creep; basic export sufficient |
| Custom theme builder | Violates simplicity principle |
| Plugin/extension system | Out of scope for v1 |
| A/B testing framework | Not needed for MVP |
