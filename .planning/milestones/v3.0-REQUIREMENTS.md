## v3.0 Requirements

**Defined:** 2026-02-05
**Core Value:** Non-technical users can manage a complete marketing department in minutes, not hours.

### Authentication & User Management

- [x] **AUTH-01**: Multi-user authentication with Clerk (login, signup, session management)
- [x] **AUTH-02**: User identity synced to Convex (userId on all new data, middleware protection)
- [x] **AUTH-03**: Data migration — existing global data assigned to "owner" user account
- [x] **AUTH-04**: Protected routes — all pages require authentication, public onboarding for signup

### Roles & Permissions

- [x] **ROLE-01**: Role-based access control with 6 roles (owner, admin, editor, reviewer, publisher, viewer)
- [x] **ROLE-02**: Permission enforcement in Convex queries/mutations (server-side, not UI-only)
- [x] **ROLE-03**: Role management UI in settings (admin can assign/change roles)
- [x] **ROLE-04**: Role-aware navigation (hide features user doesn't have access to)

### Analytics & Intelligence — Internal

- [x] **AI-01**: Internal metrics dashboard (tokens used, costs, agent activity, content created)
- [x] **AI-02**: Time-series aggregation with in-memory rollups (daily/weekly/monthly)
- [x] **AI-03**: Agent performance metrics (success rate, avg duration, cost per task by agent)
- [x] **AI-04**: Content pipeline metrics (avg time in each status, throughput, bottlenecks)

### Analytics & Intelligence — LinkedIn

- [x] **AL-01**: LinkedIn post engagement data (likes, comments, shares, impressions) via Analytics API
- [x] **AL-02**: Cached engagement snapshots (periodic fetch with dynamic TTL — hot/warm/cold)
- [x] **AL-03**: Post performance dashboard (engagement trends, best performing content)
- [x] **AL-04**: A/B content insights (compare performance across content types, topics, posting times)

### Analytics — Automated Reports

- [x] **AR-01**: Weekly performance report generated by agent (content published, engagement, costs)
- [x] **AR-02**: Monthly analytics summary with trends and recommendations
- [x] **AR-03**: Report viewable in dashboard and exportable as HTML download
- [x] **AR-04**: Report delivery via email notification (optional, Resend SDK)

### Multi-Platform Publishing — Twitter/X

- [x] **TX-01**: Twitter/X OAuth 2.0 authentication flow with PKCE (connect account)
- [x] **TX-02**: Post creation (single tweets, max 280 chars with content truncation preview)
- [x] **TX-03**: Thread support (long content auto-split into tweet threads)
- [x] **TX-04**: Connection status and rate limit display in settings
- [x] **TX-05**: Publish history with link to published tweet

### Multi-Platform Publishing — Instagram

- [x] **IG-01**: Instagram Business API integration via Facebook OAuth
- [x] **IG-02**: Image post publishing (photo + caption, 2200 char limit)
- [x] **IG-03**: Carousel support (multiple images in one post, max 10)
- [x] **IG-04**: Connection status with Facebook Business account requirement explained
- [x] **IG-05**: Instagram content guidelines validation (aspect ratio, image size checks)

### Cross-Platform Features

- [x] **CP-01**: Cross-platform scheduling (one content piece -> multiple platforms with per-platform formatting)
- [x] **CP-02**: Multi-platform preview (see how content looks on LinkedIn, Twitter, Instagram before publish)
- [x] **CP-03**: Platform-specific content adaptation (auto-truncate for Twitter, add hashtags for Instagram)
- [x] **CP-04**: Unified publishing history (all platforms in one timeline view)

### Content Version History

- [x] **VH-01**: Content version snapshots on every edit (auto-save with user attribution)
- [x] **VH-02**: Version diff view (see what changed between versions)
- [x] **VH-03**: Rollback to previous version with confirmation
- [x] **VH-04**: Audit trail (who created, edited, approved, published — with timestamps)

### UX Cross-Cutting

- [x] **UX-01**: All new interfaces in Spanish 100%
- [x] **UX-02**: Mobile responsive for all new features
- [x] **UX-03**: Toast notifications for all new actions
- [x] **UX-04**: Loading states and skeleton screens in all new views
