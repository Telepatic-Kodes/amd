## Configuration

**Environment:**
- Clerk JWT authentication via CLERK_JWT_ISSUER_DOMAIN environment variable
- Convex deployment configuration via NEXT_PUBLIC_CONVEX_URL and CONVEX_DEPLOYMENT
- OpenAI API key for LLM calls (OPENAI_API_KEY)
- Anthropic API key for fallback/legacy calls (ANTHROPIC_API_KEY)
- Resend API key for email sending (RESEND_API_KEY)
- Rate limiting window: 60,000ms (1 minute) for API requests

**Build:**
- `next.config.ts` - NextConfig with:
  - TypeScript error ignoring (split Convex dirs)
  - Turbopack bundler
  - Image optimization (AVIF/WebP formats)
  - Security headers (HSTS, CSP, MIME sniffing prevention)
  - Content Security Policy allowing: Clerk, Convex, Vercel, Anthropic API
- `postcss.config.mjs` - PostCSS plugin for Tailwind CSS 4
- `tsconfig.json` - Strict TypeScript with path aliases (@/*, @convex/*)
- `eslint.config.mjs` - ESLint rules extending Next.js core web vitals and TypeScript

## Performance Characteristics

**Frontend:**
- Target Lighthouse score > 90
- Image formats: AVIF (preferred), WebP (fallback)
- Code splitting via Next.js App Router dynamic imports
- Real-time updates via Convex WebSocket sync

**Backend:**
- Convex HTTP Router with SHA-256 token validation
- Rate limiting: 60-second windows per API key
- Serverless function timeouts: Standard Convex limits (typically 5-30 minutes depending on plan)
- Max tokens per agent execution: 4,096 (configurable per agent)

## Security Configuration

**Content Security Policy:**
```
default-src 'self'
script-src: Clerk, Cloudflare, Vercel Analytics, unsafe-inline/eval
style-src: Google Fonts, unsafe-inline
font-src: Google Fonts Gstatic
img-src: Clerk, Unsplash, data:, blob:
connect-src: Convex, Clerk, Anthropic API, Vercel Insights
frame-src: Clerk, Cloudflare
worker-src: 'self', blob:
```

**Additional Headers:**
- HSTS: 1 year with subdomains and preload
- X-Content-Type-Options: nosniff
- X-Frame-Options: DENY
- Referrer-Policy: strict-origin-when-cross-origin
- Permissions-Policy: camera=(), microphone=(), geolocation=(), interest-cohort=()
