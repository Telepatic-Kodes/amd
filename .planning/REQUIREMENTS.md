# Requirements: AMD v3.0 Intelligence & Scale

**Defined:** 2026-02-05
**Core Value:** Non-technical users can manage a complete marketing department in minutes, not hours.

## v3.0 Requirements

Requirements for v3.0 milestone. Each maps to roadmap phases.

### Authentication & User Management

- [ ] **AUTH-01**: Multi-user authentication with Clerk (login, signup, session management)
- [ ] **AUTH-02**: User identity synced to Convex (userId on all new data, middleware protection)
- [ ] **AUTH-03**: Data migration — existing global data assigned to "owner" user account
- [ ] **AUTH-04**: Protected routes — all pages require authentication, public onboarding for signup

### Roles & Permissions

- [ ] **ROLE-01**: Role-based access control with 4 roles (admin, editor, reviewer, publisher)
- [ ] **ROLE-02**: Permission enforcement in Convex queries/mutations (server-side, not UI-only)
- [ ] **ROLE-03**: Role management UI in settings (admin can assign/change roles)
- [ ] **ROLE-04**: Role-aware navigation (hide features user doesn't have access to)

### Analytics & Intelligence — Internal

- [ ] **AI-01**: Internal metrics dashboard (tokens used, costs, agent activity, content created)
- [ ] **AI-02**: Time-series aggregation with @convex-dev/aggregate (daily/weekly/monthly rollups)
- [ ] **AI-03**: Agent performance metrics (success rate, avg duration, cost per task by agent)
- [ ] **AI-04**: Content pipeline metrics (avg time in each status, throughput, bottlenecks)

### Analytics & Intelligence — LinkedIn

- [ ] **AL-01**: LinkedIn post engagement data (likes, comments, shares, impressions) via Analytics API
- [ ] **AL-02**: Cached engagement snapshots (periodic fetch, not real-time — respect rate limits)
- [ ] **AL-03**: Post performance dashboard (engagement trends, best performing content)
- [ ] **AL-04**: A/B content insights (compare performance across content types, topics, posting times)

### Analytics — Automated Reports

- [ ] **AR-01**: Weekly performance report generated by agent (content published, engagement, costs)
- [ ] **AR-02**: Monthly analytics summary with trends and recommendations
- [ ] **AR-03**: Report viewable in dashboard and exportable as PDF
- [ ] **AR-04**: Report delivery via email notification (optional)

### Multi-Platform Publishing — Twitter/X

- [ ] **TX-01**: Twitter/X OAuth 2.0 authentication flow (connect account)
- [ ] **TX-02**: Post creation (single tweets, max 280 chars with content truncation preview)
- [ ] **TX-03**: Thread support (long content auto-split into tweet threads)
- [ ] **TX-04**: Connection status and rate limit display in settings
- [ ] **TX-05**: Publish history with link to published tweet

### Multi-Platform Publishing — Instagram

- [ ] **IG-01**: Instagram Business API integration via Meta Business SDK
- [ ] **IG-02**: Image post publishing (photo + caption, 2200 char limit)
- [ ] **IG-03**: Carousel support (multiple images in one post)
- [ ] **IG-04**: Connection status with Facebook Business account requirement explained
- [ ] **IG-05**: Instagram content guidelines validation (aspect ratio, image size checks)

### Cross-Platform Features

- [ ] **CP-01**: Cross-platform scheduling (one content piece → multiple platforms with per-platform formatting)
- [ ] **CP-02**: Multi-platform preview (see how content looks on LinkedIn, Twitter, Instagram before publish)
- [ ] **CP-03**: Platform-specific content adaptation (auto-truncate for Twitter, add hashtags for Instagram)
- [ ] **CP-04**: Unified publishing history (all platforms in one timeline view)

### Content Version History

- [ ] **VH-01**: Content version snapshots on every edit (auto-save with user attribution)
- [ ] **VH-02**: Version diff view (see what changed between versions)
- [ ] **VH-03**: Rollback to previous version with confirmation
- [ ] **VH-04**: Audit trail (who created, edited, approved, published — with timestamps)

### UX Cross-Cutting

- [ ] **UX-01**: All new interfaces in Spanish 100%
- [ ] **UX-02**: Mobile responsive for all new features
- [ ] **UX-03**: Toast notifications for all new actions
- [ ] **UX-04**: Loading states and skeleton screens in all new views

## Future Requirements (v4.0+)

Deferred to future milestones. Tracked but not in current roadmap.

### Advanced Features

- **ADV-01**: TikTok / YouTube publishing integration
- **ADV-02**: Collaborative real-time editing (CRDT-based)
- **ADV-03**: Multilingual UI (i18n framework)
- **ADV-04**: Custom workflow builder (drag & drop approval flows)
- **ADV-05**: AI-powered optimal posting time recommendations
- **ADV-06**: Advanced A/B testing with statistical significance

## Out of Scope

| Feature | Reason |
|---------|--------|
| Dark mode / theming | Not core to v3.0 goals |
| TikTok / YouTube publishing | Focus on LinkedIn, Twitter/X, Instagram |
| Collaborative real-time editing | Requires CRDT; high complexity, low v3.0 priority |
| Multilingual (i18n) | Spanish-only continues |
| Custom workflow builder | Sensible defaults preferred over configuration |
| Video post publishing | Platform video APIs add significant complexity |
| Agent customization UI | Stays in backend configuration |
