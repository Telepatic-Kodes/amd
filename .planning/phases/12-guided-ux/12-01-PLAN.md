# Plan 12-01: Guided UX Layer (Full)

## Phase Goal
Users receive contextual guidance and recommendations throughout the system for faster onboarding and efficiency.

## Scope
All-in-one implementation: guidance state, next action engine, setup progress, contextual help, adaptive wizard.

## Architecture Decisions (from RESEARCH.md)
- Custom over library (zero new dependencies)
- Dual-layer state: localStorage (immediate) + Convex (persistent)
- Rules engine for "next action" recommendations
- Setup progress computed server-side from actual data
- Quick Mode after 3 onboarding completions
- ContextualHelp component with dismissal persistence

## Tasks

### Task 1: Schema + Guidance State (DONE)
- Added `userGuidance` table to `convex/schema.ts`
- Created `convex/guidance.ts` with queries (getGuidance, getSetupProgress) and mutations (initGuidance, completeSetupStep, trackFeatureDiscovery, toggleQuickMode, incrementOnboardingCompletion)
- Created `lib/guidance-state.ts` for localStorage management (tooltips, next action dismissals, feature discovery, quick mode preferences)

### Task 2: Next Action Engine + Card (DONE)
- Created `lib/next-action.ts` with 9 priority-ordered rules evaluating DashboardState
- Created `components/guided-ux/NextActionCard.tsx` with Framer Motion animations
- Integrated into Dashboard page above metrics grid
- 24-hour dismissal with localStorage persistence
- Uses actual Convex queries for real-time state evaluation

### Task 3: Setup Progress (DONE)
- Created `components/guided-ux/SetupProgress.tsx` with expandable step list
- 7 weighted steps (company, goals, feeds, content, campaigns, analytics, settings)
- Animated progress bar with gradient
- Server-side progress computation via `getSetupProgress` query
- Auto-detects completed steps from actual data

### Task 4: Contextual Help (DONE)
- Created `components/guided-ux/ContextualHelp.tsx` with positioned tooltips
- Supports top/bottom/left/right placement
- `showOnce` prop for permanent dismissal via localStorage
- Click-outside and Escape key to close
- Added to 3 dashboard metric cards with Spanish explanations

### Task 5: Adaptive Wizard + Integration (DONE)
- Created `components/guided-ux/QuickModeToggle.tsx`
- Added "Guía UX" settings category with toggle and instructions
- Onboarding page increments completion count on launch
- Analytics page auto-marks "analyticsViewed" step
- Settings page auto-marks "settingsReviewed" step
- Language: 11 Spanish translations for guided UX features
