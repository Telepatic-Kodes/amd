2. In convex/schema.ts, add two tables AFTER the auditLog table:

   a) `reports` table:
   ```typescript
   reports: defineTable({
     userId: v.string(),                    // Clerk userId who owns this report
     type: v.union(v.literal("weekly"), v.literal("monthly")),
     title: v.string(),                     // "Reporte semanal - 3 Feb 2026"
     periodStart: v.number(),               // Start timestamp of report period
     periodEnd: v.number(),                 // End timestamp
     // Report content (stored as HTML for display/email)
     htmlContent: v.string(),               // Full HTML report body
     // Key metrics snapshot (for quick display without parsing HTML)
     metrics: v.object({
       totalContent: v.number(),
       contentPublished: v.number(),
       totalTokens: v.number(),
       totalCost: v.number(),
       successRate: v.number(),
       topPlatform: v.optional(v.string()),
       totalEngagement: v.optional(v.number()),
     }),
     // AI-generated narrative
     narrative: v.optional(v.string()),
     // Delivery status
     emailSent: v.boolean(),
     emailSentAt: v.optional(v.number()),
     emailError: v.optional(v.string()),
     generatedAt: v.number(),
   })
     .index("by_userId", ["userId"])
     .index("by_userId_type", ["userId", "type"])
     .index("by_generatedAt", ["generatedAt"]),
   ```

   b) `reportSettings` table:
   ```typescript
   reportSettings: defineTable({
     userId: v.string(),
     emailEnabled: v.boolean(),             // Toggle email delivery
     frequency: v.union(v.literal("weekly"), v.literal("monthly"), v.literal("both")),
     recipientEmail: v.optional(v.string()), // Override email (defaults to user's Clerk email)
     includeNarrative: v.boolean(),          // Include AI-generated insights
     createdAt: v.number(),
     updatedAt: v.number(),
   })
     .index("by_userId", ["userId"]),
   ```

3. Create convex/reports.ts with:

   a) **Query: getUserReportSettings({ })** — Returns user's report settings or defaults
   - Requires auth, gets userId
   - Query reportSettings by userId
   - If not found, return defaults: { emailEnabled: false, frequency: "weekly", includeNarrative: true }

   b) **Mutation: updateReportSettings({ emailEnabled, frequency, recipientEmail, includeNarrative })** — Upsert settings
   - Requires auth, gets userId
   - Upsert into reportSettings table
   - All args optional (partial update)

   c) **Query: getReportHistory({ limit? })** — Returns user's past reports
   - Requires auth, gets userId
   - Query reports by userId, order desc by generatedAt
   - Take limit (default 20)
   - Return array: { _id, type, title, periodStart, periodEnd, metrics, emailSent, generatedAt }
   - Don't return htmlContent (too large for list queries)

   d) **Query: getReportById({ id })** — Returns full report including HTML
   - Requires auth, gets userId
   - Verify report belongs to user
   - Return full report doc

   e) **Internal helper: buildReportMetrics(ctx, userId, periodStart, periodEnd)** — Aggregates all analytics data
   - Query analytics data for the period (use existing analytics queries pattern, NOT API calls)
   - Query content table: count total, count published in period
   - Query executions: total tokens, total cost, success rate
   - Query linkedinEngagement for engagement totals
   - Return metrics object matching the schema

   f) **Internal helper: buildReportHtml(title, metrics, narrative, periodLabel)** — Generates HTML report
   - Professional HTML email template (inline CSS for email compatibility)
   - Dark theme matching AMD brand (bg-zinc-900, text-zinc-100)
   - Sections: Header with period, Key Metrics (4 cards), Content Summary, AI Insights
   - All labels in Spanish
   - Mobile-responsive (max-width: 600px table layout)
   - Return HTML string

   g) **Action: generateWeeklyReport({ })** — Main weekly report generator
   - Get all users with emailEnabled settings (or generate for all users)
   - For each user:
     - Calculate period: last Monday to this Monday
     - Call buildReportMetrics to get metrics
     - If includeNarrative: Call callClaude with CMO prompt for AI narrative
       - Prompt: "Eres el CMO de un departamento de marketing AI. Analiza estas métricas de la semana y escribe un resumen ejecutivo de 2 párrafos en español destacando logros, áreas de mejora y recomendaciones."
     - Call buildReportHtml to generate HTML
     - Insert report into reports table
     - If emailEnabled: Send email via Resend API
       - Use Resend's send() with from: "AMD Reports <reports@amd.dev>", to: user email
       - HTML body = the generated report
       - Update emailSent status
   - Return count of reports generated

   h) **Action: generateMonthlyReport({ })** — Same as weekly but for 30-day period
   - Period: first day of previous month to first day of current month
   - Title: "Reporte mensual - Enero 2026"
   - Same flow as weekly but with longer period

   i) **Action: generateReportNow({ type })** — Manual trigger for immediate report
   - Requires auth
   - Gets userId
   - Generates report for current user only (weekly or monthly)
   - Returns the new report ID

   IMPORTANT: For email sending, use Resend SDK:
   ```typescript
   import { Resend } from "resend";
   const resend = new Resend(process.env.RESEND_API_KEY);
   await resend.emails.send({
     from: "AMD Reports <reports@resend.dev>",  // Use resend.dev for testing
     to: recipientEmail,
     subject: reportTitle,
     html: htmlContent,
   });
   ```

   If RESEND_API_KEY is not set, skip email sending and just store the report (graceful degradation).

   All error messages in Spanish.
