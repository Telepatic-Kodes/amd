  <action>
Create `convex/controlCenter.ts` with the following queries:

**1. `getControlCenterStatus` query (no args):**
- Fetches ALL agents with `ctx.db.query("agents").collect()` (37 agents is small, safe to collect)
- Groups agents by department into a record: `Record<string, Agent[]>`
- Counts agents by status: `{ active: number, paused: number, error: number, maintenance: number }`
- Returns `{ agentsByDepartment, statusCounts, totalAgents }`
- This is the SINGLE aggregated subscription that replaces 37 individual subscriptions (Pitfall #1 prevention)

**2. `getRecentActivity` query (args: { limit: optional number, departmentFilter: optional string }):**
- Fetches recent executions using `ctx.db.query("executions").withIndex("by_timestamp").order("desc").take(limit || 50)`
- Fetches recent tasks using `ctx.db.query("tasks").order("desc").take(limit || 50)`
- For each execution, resolves the agent name by looking up `ctx.db.get(exec.agentId)` (batch the agent lookups by collecting unique agentIds first, then looking up each once)
- If departmentFilter is provided, filter results to only include agents from that department
- Merges and sorts by timestamp descending
- Returns array of activity items: `{ id, type: "execution" | "task", agentName, agentId, department, description, status, timestamp, tokensUsed?, duration? }`
- For execution items: description = `"Ejecución ${exec.status === 'success' ? 'exitosa' : 'fallida'}"` with tokensUsed and duration
- For task items: description = task.title with task.status

**3. `getControlCenterMetrics` query (no args):**
- Fetches last 100 executions: `ctx.db.query("executions").withIndex("by_timestamp").order("desc").take(100)`
- Calculates: totalTokens (sum of tokensUsed.total), totalCost (sum of cost), avgDuration, successRate
- Fetches task counts: total tasks, completed, failed, running (using status index)
- For "today" metrics: filter executions/tasks where timestamp > startOfToday
- Returns `{ tokens: { total, today }, tasks: { completed, failed, running, completedToday }, successRate, avgDuration, totalCost }`

Import patterns from existing `convex/functions.ts`. Use the same `query` import from `"./_generated/server"` and `v` from `"convex/values"`.

IMPORTANT: Use `v.optional()` for optional args. Use `.take(limit)` instead of `.collect()` on large tables (tasks, executions). Agents table (37 rows) is safe to `.collect()`.
