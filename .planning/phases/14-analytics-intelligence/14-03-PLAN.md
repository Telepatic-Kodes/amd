Create a `components/analytics/` directory with three components and a utility file.

**1. `DateRangeFilter.tsx`**
"use client" component. Props: `{ value: { startDate: number; endDate: number; label: string }; onChange: (range: { startDate: number; endDate: number; label: string }) => void }`.

Renders a row of preset buttons + custom date inputs:
- "7 dias" (last 7 days)
- "30 dias" (last 30 days)
- "90 dias" (last 90 days)
- "Personalizado" (shows two date input fields when clicked)

Styling: dark theme matching existing UI (bg-zinc-900, border-zinc-800, text-zinc-300). Active button gets bg-indigo-600 text. Use Tailwind classes consistent with existing components. Buttons are pill-shaped (rounded-full px-4 py-1.5 text-sm).

For custom range: show two `<input type="date">` fields with dark styling. When dates change, call onChange with timestamps.

Export: `DateRangeFilter` as named export.

**2. `ContentPerformanceTable.tsx`**
"use client" component. Props: `{ data: Array<{ contentId: string; title: string; type: string; publishedAt?: number; engagement: { likes: number; comments: number; shares: number; impressions: number; engagement_rate?: number } | null }>; isLoading: boolean }`.

Renders a table with columns:
- Titulo (title, truncated to 50 chars)
- Tipo (content type, with colored badge)
- Likes (with heart icon)
- Comentarios (with message-circle icon)
- Compartidos (shares, with share-2 icon)
- Impresiones (impressions, formatted with K/M)
- Tasa de Engagement (engagement_rate as percentage, colored: green > 3%, yellow 1-3%, red < 1%)

Sort by total engagement (likes+comments+shares) desc by default. Show "Sin datos de LinkedIn" in muted text for rows where engagement is null.

Use existing Card, Badge components. Dark theme table matching the existing Recent Executions table style in analytics/page.tsx. Include Skeleton loading state.

**3. `CsvExportButton.tsx`**
"use client" component. Props: `{ startDate: number; endDate: number }`.

Button that says "Exportar CSV" with a Download icon (from lucide-react). On click:
- Calls `useQuery(api.analytics.getAnalyticsExportData, { startDate, endDate })` -- but since this is reactive, pre-fetch the data with useQuery at component level
- Calls `exportToCsv()` utility with the data
- Shows a toast "Datos exportados correctamente" on success

Use existing Button component styling or create a styled button matching the dark theme.

**4. `lib/csv-export.ts`**
Utility function `exportToCsv(data: { executions: any[]; tasks: any[]; content: any[] }, filename?: string)`.

Logic:
- Create 3 CSV sheets combined into one file with section headers
- Section 1: "## Ejecuciones" -- columns: Fecha, Agente, Estado, Tokens, Costo, Duracion
- Section 2: "## Tareas" -- columns: Fecha, Titulo, Tipo, Prioridad, Estado
- Section 3: "## Contenido" -- columns: Fecha, Titulo, Tipo, Estado, Likes, Comentarios, Compartidos, Impresiones
- Format dates as ISO strings, costs as fixed 4 decimals
- Create Blob, trigger download via hidden anchor element
- Default filename: `amd-analytics-{date}.csv`

Export: `exportToCsv` as named export.

All components MUST use Spanish labels (UX-01). All text visible to users in Spanish.
