# Plan 11-01: LinkedIn Publishing Integration (Full)

## Phase Goal
Users can publish approved content directly to LinkedIn as proof-of-concept for multi-platform publishing.

## Scope
All-in-one implementation: OAuth 2.0 flow, backend module, frontend components, publishing, preview.

## Architecture Decisions (from RESEARCH.md)
- Personal profile only (no org pages = no LinkedIn review needed)
- Custom OAuth via Convex HTTP Actions (no auth.js dependency)
- Raw fetch() for LinkedIn API calls (matches existing patterns)
- Single LinkedIn account per AMD instance
- Text-only posts for MVP (image support as future follow-up)
- Manual "Publish to LinkedIn" button (not automatic)
