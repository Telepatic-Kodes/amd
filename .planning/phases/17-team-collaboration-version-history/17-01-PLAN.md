1. In convex/schema.ts, update the `users` table `role` field to include the new roles. The current roles are: "owner", "admin", "editor", "viewer". Change to:
   ```
   role: v.union(
     v.literal("owner"),
     v.literal("admin"),
     v.literal("editor"),
     v.literal("reviewer"),
     v.literal("publisher"),
     v.literal("viewer")
   )
   ```
   Keep "owner" (system owner from Phase 13) and "viewer" (read-only). Add "reviewer" and "publisher" as new roles. This is backward-compatible since existing users have "owner" or "editor" roles.

2. Create convex/lib/permissions.ts with:

   a) **ROLES constant** — ordered hierarchy: owner > admin > editor > reviewer > publisher > viewer

   b) **PERMISSIONS map** — defines what each role can do:
   ```typescript
   const PERMISSIONS = {
     // Content lifecycle
     "content:create": ["owner", "admin", "editor"],
     "content:edit": ["owner", "admin", "editor"],
     "content:delete": ["owner", "admin"],
     "content:review": ["owner", "admin", "reviewer"],     // Send to review, approve, reject
     "content:publish": ["owner", "admin", "publisher"],    // Publish approved content
     "content:archive": ["owner", "admin"],

     // User/team management
     "users:manage": ["owner", "admin"],                    // Assign roles, invite
     "users:view": ["owner", "admin"],                      // See team members list

     // System settings
     "settings:manage": ["owner", "admin"],
     "settings:view": ["owner", "admin", "editor", "reviewer", "publisher", "viewer"],

     // Analytics
     "analytics:view": ["owner", "admin", "editor", "reviewer", "publisher"],
     "analytics:export": ["owner", "admin"],

     // Platform connections
     "platforms:manage": ["owner", "admin"],
     "platforms:view": ["owner", "admin", "editor", "publisher"],
   } as const;
   ```

   c) **getUserRole(ctx)** — async function that:
   - Gets identity via requireAuth(ctx)
   - Queries users table by clerkId
   - Returns the role string (defaults to "viewer" if user not found — safe fallback)

   d) **hasPermission(ctx, permission)** — async function that:
   - Calls getUserRole(ctx)
   - Checks if role is in PERMISSIONS[permission]
   - Returns boolean

   e) **requireRole(ctx, permission)** — async function that:
   - Calls hasPermission
   - Throws "No tienes permiso para realizar esta acción." if false
   - Returns void (used as a guard)

   f) **canTransitionContent(role, fromStatus, toStatus)** — pure function that:
   - Maps content status transitions to required permissions:
     - draft → review: "content:edit" (any editor can send to review)
     - review → approved: "content:review" (only reviewers/admins)
     - review → revision_needed: "content:review"
     - revision_needed → review: "content:edit"
     - approved → published: "content:publish" (only publishers/admins)
     - approved → scheduled: "content:publish"
     - scheduled → published: "content:publish"
     - published → archived: "content:archive"
     - archived → draft: "content:edit"
   - Returns boolean

   Export all: ROLES, PERMISSIONS, getUserRole, hasPermission, requireRole, canTransitionContent
