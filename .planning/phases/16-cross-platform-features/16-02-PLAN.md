Create `CrossPlatformPublishPanel.tsx`:

Props: `contentId: Id<"content">`, `contentBody: string`, `contentStatus: string`, `contentHashtags?: string[]`, `className?: string`

Component structure:
1. **Platform selection section** — Three checkboxes with platform icons and labels:
   - LinkedIn checkbox with blue LinkedIn icon (#0A66C2) and connection status
   - Twitter/X checkbox with blue Twitter icon (#1DA1F2) and connection status
   - Instagram checkbox with gradient Instagram icon and connection status
   - Each checkbox is disabled if platform is not connected (query each platform's connection)
   - Use `useQuery(api.linkedin.queries.getConnection)`, `useQuery(api.twitter.queries.getConnection)`, `useQuery(api.instagram.queries.getConnection)` to get connection status
   - Show "No conectado" in zinc-500 text when not connected

2. **Side-by-side preview section** — Only shows for checked platforms. Renders `PlatformPreviewGrid` component with only the selected platforms.

3. **Instagram image URL input** — Conditionally shown when Instagram is checked. Text input for image URL (HTTPS required). Same pattern as existing `PublishToInstagramButton`.

4. **Publish button** — "Publicar en {N} plataformas" button (indigo-600 bg). Disabled when no platforms selected or publishing in progress.
   - Uses `useAction(api.crossPlatform.actions.publishToMultiplePlatforms)` (NOT useMutation — this is a Convex action)
   - On click: calls publishToMultiplePlatforms with contentId, selected platforms array, and optional instagramImageUrl
   - Shows loading spinner during publish
   - On success: toast per platform with result (green for success, red for failure). Use `sonner` toast or existing toast pattern.
   - Format: "LinkedIn: Publicado correctamente" / "Twitter: Error - {message}"

5. **Publish status summary** — Below button, show colored dots per platform for already-published content (same pattern as current `ContentDetailPlatformPublish.tsx`)

Replace usage of `ContentDetailPlatformPublish` in content/page.tsx with `CrossPlatformPublishPanel`. Keep the old component file for backward compatibility but update the content detail view to use the new panel.
