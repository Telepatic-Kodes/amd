### Task 3: Create RichTextEditor Component

**Description:** Create isolated RichTextEditor component with TipTap core functionality.

**Steps:**
1. Create `components/content/RichTextEditor.tsx`
2. Set up TipTap editor with `useEditor` hook
3. Configure extensions:
   - StarterKit (includes Bold, Italic, Heading, BulletList, OrderedList, CodeBlock, etc.)
   - Link extension with custom configuration
   - CharacterCount extension
4. Map keyboard shortcuts:
   - Ctrl+B = Bold
   - Ctrl+I = Italic
   - Ctrl+E = Code
   - Ctrl+Shift+7 = BulletList
   - Ctrl+Shift+8 = OrderedList
   - Ctrl+Alt+1/2/3 = Heading 1/2/3
5. Implement onChange callback to update parent
6. Add performance optimization: `shouldRerenderOnTransaction: false`
7. Add error boundary wrapper
8. Style with Tailwind dark theme (bg-zinc-950, border-zinc-800, text-white)

**Acceptance:**
- [ ] Component renders without errors
- [ ] Keyboard shortcuts work (Ctrl+B toggles bold, etc.)
- [ ] onChange callback fires and updates parent
- [ ] No console warnings or errors
- [ ] Performance optimized (no unnecessary re-renders)

**Component structure:**
```typescript
interface RichTextEditorProps {
  content: string;
  onChange: (html: string) => void;
  readOnly?: boolean;
  placeholder?: string;
}

export function RichTextEditor({ content, onChange, readOnly = false, placeholder }: RichTextEditorProps) {
  const editor = useEditor({
    extensions: [
      StarterKit,
      Link.configure({
        openOnClick: false,
        autolink: true,
      }),
      CharacterCount.configure({
        limit: 100000,
      }),
    ],
    content,
    editable: !readOnly,
    onUpdate: ({ editor }) => {
      onChange(editor.getHTML());
    },
    shouldRerenderOnTransaction: false,
  });

  return <div className="editor-container">{/* ProseMirror DOM */}</div>;
}
```
