# Plan 07-03: Preview & Validation

**Objective:** Add Write/Preview tab toggle, implement EditorStatusBar with character/word count, add export functionality.

**Effort:** 4-6 hours
**Risk:** Low

## Tasks

### Task 1: Create EditorPreview Component

**Description:** Create read-only editor instance for previewing formatted content.

**Steps:**
1. Create `components/content/EditorPreview.tsx`
2. Create read-only TipTap editor instance
3. Display HTML content safely (TipTap schema prevents XSS)
4. Apply prose typography classes for better readability
5. Hide toolbar and editing elements
6. Style preview to match published content appearance

**Acceptance:**
- [ ] Preview renders HTML correctly
- [ ] Formatting visible (bold, italic, headers, lists, etc.)
- [ ] No editing possible (read-only)
- [ ] No XSS vulnerabilities
- [ ] Typography matches publishing target

---

### Task 2: Add Write/Preview Tab Toggle

**Description:** Add tab interface to switch between Edit and Preview modes.

**Steps:**
1. Add tabs above editor/preview in EditContentModal
2. Tab 1: "Write" (shows RichTextEditor)
3. Tab 2: "Preview" (shows EditorPreview)
4. Use React state to track active tab
5. Smooth transition between tabs (Framer Motion fade)
6. Remember last active tab (optional: localStorage)

**Acceptance:**
- [ ] Tabs display correctly
- [ ] Tab switching works
- [ ] Content syncs between tabs
- [ ] Smooth animations

---

### Task 3: Create EditorStatusBar Component

**Description:** Display real-time character and word count.

**Steps:**
1. Create `components/content/EditorStatusBar.tsx`
2. Display:
   - Character count (using CharacterCount extension from TipTap)
   - Word count (using stripHtmlTags + countWords utilities)
   - Reading time estimate (words / 200)
   - Validation status ("Ready" or "Below minimum")
3. Show warning if content < 50 chars
4. Style with Tailwind (small, subtle, right-aligned)
5. Update in real-time as user types

**Acceptance:**
- [ ] Character count accurate
- [ ] Word count accurate (excludes HTML)
- [ ] Reading time correct
- [ ] Validation warning appears/disappears correctly
- [ ] Updates smoothly as user types

---

### Task 4: Add Export Functions

**Description:** Implement Copy HTML and Download as File functionality.

**Steps:**
1. Add buttons to EditorStatusBar or toolbar:
   - "Copy HTML" button
   - "Download as HTML" button
2. Use `copyHtmlToClipboard()` utility for copy
3. Use `downloadAsFile()` utility for download
4. Show success toast after copy
5. Generate filename based on content title: `{title}-{timestamp}.html`

**Acceptance:**
- [ ] Copy HTML works (content in clipboard)
- [ ] Download works (file downloads to browser)
- [ ] Toast notifications appear
- [ ] Filename reasonable and timestamped

---

### Task 5: Test Preview & Export

**Description:** Verify preview and export functionality.

**Steps:**
1. Test Write tab: Content editable
2. Test Preview tab: Content read-only, formatted correctly
3. Test switching between tabs multiple times
4. Test Copy HTML: Paste in text editor, verify HTML preserved
5. Test Download: Open downloaded HTML in browser
6. Test with various content (headers, lists, code blocks, links)

**Acceptance:**
- [ ] Preview accurate
- [ ] Export creates valid HTML
- [ ] Tab switching smooth
- [ ] No data loss switching tabs
