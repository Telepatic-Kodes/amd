# Plan 07-02: EditorToolbar & BubbleMenu

**Objective:** Extract and style EditorToolbar component, add BubbleMenu for inline formatting, implement LinkDialog for URL insertion.

**Effort:** 6-8 hours
**Risk:** Low

## Tasks

### Task 1: Create EditorToolbar Component

**Description:** Extract toolbar buttons into separate, reusable EditorToolbar component.

**Steps:**
1. Create `components/content/EditorToolbar.tsx`
2. Design toolbar with button groups:
   - **Text Formatting:** Bold, Italic, Strikethrough, Code
   - **Headings:** H1, H2, H3
   - **Lists:** Bullet List, Ordered List
   - **Blocks:** Blockquote, Code Block, Horizontal Rule
   - **Links:** Insert Link
   - **Undo/Redo:** Undo, Redo
3. Use Lucide React icons for buttons (Bold, Italic, Heading, List, etc.)
4. Style buttons with Tailwind (hover effects, active states)
5. Accept `editor` prop from TipTap useEditor hook
6. Implement button onClick handlers to execute editor commands
7. Add visual feedback for active states (bold button highlighted when text is bold)

**Acceptance:**
- [ ] Toolbar renders with all buttons
- [ ] Button clicks execute editor commands
- [ ] Active states show correctly (bold button highlighted in bold text)
- [ ] Icons are clear and recognizable
- [ ] Responsive on small screens

**Example structure:**
```typescript
export function EditorToolbar({ editor }: { editor: Editor | null }) {
  if (!editor) return null;

  return (
    <div className="flex flex-wrap gap-1 border-b border-zinc-800 bg-zinc-900/50 p-2">
      <button
        onClick={() => editor.chain().focus().toggleBold().run()}
        className={cn("px-2 py-1 rounded", editor.isActive('bold') && "bg-indigo-500")}
        title="Bold (Ctrl+B)"
      >
        <Bold className="h-4 w-4" />
      </button>
      {/* ... more buttons */}
    </div>
  );
}
```

### Task 4: Responsive Toolbar Design

**Description:** Make toolbar responsive for mobile screens.

**Steps:**
1. Hide advanced formatting buttons on mobile (< 640px)
2. Keep essential buttons: Bold, Italic, Lists, Link
3. Use Tailwind responsive classes (`hidden sm:block`)
4. Test on mobile screen sizes (375px, 480px, 640px)
5. Ensure touch targets are at least 44x44px

**Acceptance:**
- [ ] Toolbar appears correctly on desktop
- [ ] Advanced options hidden on mobile
- [ ] Touch targets properly sized
- [ ] No horizontal scroll needed on mobile
