<task type="auto">
  <name>Task 2: Create orchestrator action for cron</name>
  <files>convex/feeds/syncAllFeeds.ts</files>
  <action>
Create `convex/feeds/syncAllFeeds.ts` with the cron-triggered orchestrator:

1. **syncAllFeeds** action:
   - Args: `{ frequency: "hourly" | "daily" | "weekly" }`
   - Query feeds due for sync using internal query `getFeedsDueForSync`
   - For each feed, schedule with staggered delay to avoid thundering herd
   - Stagger formula: `index * 1000` (1 second apart)
   - Log summary: "Scheduled N feeds for sync"
   - Return `{ scheduledCount: number, feedIds: string[] }`

Implementation:
```typescript
import { v } from "convex/values";
import { action } from "../_generated/server";
import { internal } from "../_generated/api";

export const syncAllFeeds = action({
  args: {
    frequency: v.union(
      v.literal("hourly"),
      v.literal("daily"),
      v.literal("weekly")
    ),
  },
  handler: async (ctx, args): Promise<{ scheduledCount: number; feedIds: string[] }> => {
    // 1. Get feeds due for sync
    const feeds = await ctx.runQuery(
      internal.feeds.queries.getFeedsDueForSync,
      { frequency: args.frequency }
    );

    // 2. Schedule each feed with staggered delay (fan-out)
    const feedIds: string[] = [];
    for (let i = 0; i < feeds.length; i++) {
      const feed = feeds[i];
      const delayMs = i * 1000; // 1 second stagger

      await ctx.scheduler.runAfter(
        delayMs,
        internal.feeds.fetchFeed.fetchFeed,
        { feedId: feed._id }
      );

      feedIds.push(feed.feedId);
    }

    console.log(`[syncAllFeeds] Scheduled ${feeds.length} feeds for ${args.frequency} sync`);

    return {
      scheduledCount: feeds.length,
      feedIds,
    };
  },
});
```

The 1-second stagger prevents:
- Rate limiting from target servers
- Thundering herd on database writes
- Memory spikes from parallel processing
