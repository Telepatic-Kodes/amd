<task type="auto">
  <name>Task 1: Create feed CRUD mutations</name>
  <files>convex/feeds/mutations.ts</files>
  <action>
Create `convex/feeds/mutations.ts` with PUBLIC mutations for feed management:

1. **addFeed** mutation:
   - Args: `{ url: string, name: string, category: string, syncFrequency: "hourly" | "daily" | "weekly" }`
   - Generate UUID for feedId using `crypto.randomUUID()`
   - Validate URL format (must start with http:// or https://)
   - Check for duplicate URL (query by_url index, return error if exists)
   - Insert into feeds table with status "active", consecutiveErrors 0
   - Return the created feed document

2. **updateFeed** mutation:
   - Args: `{ feedId: Id<"feeds">, name?: string, category?: string, syncFrequency?: "hourly" | "daily" | "weekly" }`
   - Patch only provided fields + updatedAt
   - Return updated feed

3. **deleteFeed** mutation:
   - Args: `{ feedId: Id<"feeds"> }`
   - Delete all feedItems with this feedId (query by_feedId index, delete each)
   - Delete all feedSyncLog entries with this feedId
   - Delete the feed itself
   - Return { success: true, deletedItems: count }

4. **pauseFeed** mutation:
   - Args: `{ feedId: Id<"feeds"> }`
   - Patch status to "paused", updatedAt to now
   - Return updated feed

5. **resumeFeed** mutation:
   - Args: `{ feedId: Id<"feeds"> }`
   - Patch status to "active", consecutiveErrors to 0, updatedAt to now
   - Return updated feed

Use `mutation` from `convex/server` (NOT internalMutation) since these are called from frontend.
Import `v` from `convex/values` for args validation.
  </action>

<task type="auto">
  <name>Task 2: Create public queries for dashboard</name>
  <files>convex/feeds/publicQueries.ts</files>
  <action>
Create `convex/feeds/publicQueries.ts` with PUBLIC queries for dashboard:

1. **listAllFeeds** query:
   - Args: `{ status?: "active" | "paused" | "error" }` (optional filter)
   - Return all feeds, optionally filtered by status
   - Include computed field: itemCount (count of feedItems for this feed)
   - Sort by name ascending

2. **getFeedDetails** query:
   - Args: `{ feedId: Id<"feeds"> }`
   - Return feed document with:
     - All feed fields
     - itemCount: number of feedItems
     - lastSync: most recent feedSyncLog entry (if any)

3. **listFeedItems** query:
   - Args: `{ feedId: Id<"feeds">, limit?: number }` (default limit 20)
   - Query feedItems by_feedId_publishedAt index
   - Order descending by publishedAt
   - Take limit items
   - Return items with all fields

4. **getLatestSyncLog** query:
   - Args: `{ feedId: Id<"feeds">, limit?: number }` (default 5)
   - Query feedSyncLog by_feedId_syncedAt index
   - Order descending by syncedAt
   - Return sync history

5. **listRecentItems** query:
   - Args: `{ limit?: number }` (default 10)
   - Query feedItems by_publishedAt index
   - Order descending
   - Take limit items
   - Join with feeds table to include feed name
   - Return items with feedName field

Use `query` from `convex/server` for public access.
  </action>

  <done>Five public queries available for dashboard: listAllFeeds, getFeedDetails, listFeedItems, getLatestSyncLog, listRecentItems</done>
</task>
