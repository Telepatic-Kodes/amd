Create `lib/file-parsers.ts` with file parsing utilities for PDF, DOCX, and TXT files.

**Structure:**

```typescript
import pdfParse from 'pdf-parse';
import mammoth from 'mammoth';

export interface ParsedContent {
  text: string;        // Plain text extracted
  html: string;        // HTML-formatted content (for TipTap)
  metadata: {
    fileName: string;
    fileType: string;
    fileSize: number;
    wordCount: number;
    readingTime: number;
  };
}

export interface ParseError {
  error: string;
  fileName: string;
  fileType: string;
}

// Parse PDF file to text and basic HTML
export async function parsePdf(file: File): Promise<ParsedContent>

// Parse DOCX file to HTML (preserves formatting)
export async function parseDocx(file: File): Promise<ParsedContent>

// Parse TXT file (plain text to HTML with paragraphs)
export async function parseTxt(file: File): Promise<ParsedContent>

// Main parser function - routes to correct parser based on file type
export async function parseFile(file: File): Promise<ParsedContent | ParseError>

// Validate file before parsing
export function validateFile(file: File, maxSizeMB: number = 10): { valid: boolean; error?: string }
```

**Implementation details:**

1. **parsePdf:**
   - Use pdf-parse to extract text
   - Convert extracted text to basic HTML (wrap in `<p>` tags, preserve line breaks as `<br>`)
   - Handle errors gracefully (encrypted PDFs, corrupted files)

2. **parseDocx:**
   - Use mammoth.convertToHtml to extract HTML
   - Mammoth preserves formatting (bold, italic, headings, lists)
   - HTML output is TipTap-compatible (clean semantic HTML)

3. **parseTxt:**
   - Read file as text using FileReader
   - Split by double line breaks into paragraphs
   - Wrap each paragraph in `<p>` tags
   - Preserve single line breaks as `<br>`

4. **parseFile:**
   - Check file.type to determine format
   - Route to appropriate parser (parsePdf, parseDocx, parseTxt)
   - Return ParseError if unsupported type
   - Supported types: application/pdf, application/vnd.openxmlformats-officedocument.wordprocessingml.document, text/plain

5. **validateFile:**
   - Check file size (max 10MB default)
   - Check file type (PDF, DOCX, TXT only)
   - Return { valid: boolean, error?: string }

**Metadata calculation:**
- wordCount: Split text by whitespace, filter empty
- readingTime: Math.ceil(wordCount / 200) (200 words/min)

**Error handling:**
- Try/catch around all parsing operations
- Return ParseError with descriptive message
- Handle edge cases: empty files, corrupted files, unsupported encodings
