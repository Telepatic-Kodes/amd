# Plan 20-01: Error Boundaries + Spanish Error Dictionary

## Goal
Every page crash shows a styled, recoverable error UI in Spanish instead of a white screen. Network errors and auth failures produce actionable messages.

## Requirements
ERR-01, ERR-02, ERR-03, ERR-07

## Current State
- `app/global-error.tsx` exists (root level)
- `app/(dashboard)/error.tsx` exists (dashboard route group)
- No per-page error boundaries
- No error classification
- No offline detection
- No Spanish error dictionary

## Tasks

### Task 1: Spanish Error Dictionary + Error Classifier
Create `lib/errors.ts`:
- `ErrorCode` enum (NETWORK, AUTH_EXPIRED, AUTH_UNAUTHORIZED, VALIDATION, CONVEX, AI_AGENT, UNKNOWN)
- `classifyError(error: unknown): ClassifiedError` — maps raw errors to codes
- `getErrorMessage(code: ErrorCode): { title: string, description: string, action?: string }` — Spanish messages
- `isNetworkError(error: unknown): boolean` — check for fetch/connection failures

### Task 2: Reusable ErrorFallback Component
Create `components/ui/ErrorFallback.tsx`:
- Props: `{ error: Error, reset: () => void, compact?: boolean }`
- Uses `classifyError` to show appropriate Spanish message
- "Reintentar" button calls `reset()`
- "Ir al inicio" link for unrecoverable errors
- `compact` mode for inline error display (inside cards/panels)
- Matches Warm Atelier design (stone palette, orange accents)

### Task 3: Per-Page Error Boundaries
Create `error.tsx` files for routes that don't have one:
- `app/(dashboard)/content/error.tsx`
- `app/(dashboard)/brand/error.tsx`
- `app/(dashboard)/settings/error.tsx`
- `app/(dashboard)/analytics/error.tsx`
- `app/(dashboard)/control-center/error.tsx`
- `app/(dashboard)/results/error.tsx`
All use `ErrorFallback` component.

### Task 4: Network Error Detection
Create `components/ui/OfflineBanner.tsx`:
- Uses `navigator.onLine` + `online`/`offline` events
- Shows fixed banner at top: "Sin conexión a internet — Los cambios se sincronizarán al reconectar"
- Auto-hides when back online with success toast
- Add to LayoutShell.tsx
