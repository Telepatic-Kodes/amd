# Plan 20-02: Zod Validation + Sanitization + AI Agent Error Messages

## Goal
All user input is validated client-side (inline errors) and server-side (Convex rejects), with XSS prevention and specific AI agent failure messages.

## Requirements
ERR-04, ERR-05, ERR-06, ERR-08

## Current State
- No Zod — all validation is manual inline
- No sanitization library
- AI errors show generic "Error desconocido"
- Convex uses `v.*` validators (type-safe but no business rules)

## Tasks

### Task 1: Install Dependencies
```bash
npm install zod dompurify
npm install -D @types/dompurify
```

### Task 2: Shared Validation Schemas
Create `lib/schemas.ts`:
- `contentSchema` — title (5-120 chars), body (50+ chars), type (union of 12 types), seo fields
- `brandProfileSchema` — name (2-100), industry, voice tone, colors
- `settingsSchema` — API key format validation, URL format
- All with Spanish error messages via `.message()`

### Task 3: Client-Side Validation Integration
Update key forms to use Zod:
- `UploadContentForm.tsx` — replace manual validateForm() with contentSchema
- `AddSourceDialog.tsx` — validate URL format
- Show inline field-level errors (not just form-level)
- Pattern: `schema.safeParse()` → map errors to field names → display under inputs

### Task 4: Input Sanitization
Create `lib/sanitize.ts`:
- `sanitizeHtml(input: string): string` — uses DOMPurify
- `sanitizeMarkdown(input: string): string` — strips dangerous tags but keeps formatting
- Integrate into content creation/editing mutations and components

### Task 5: AI Agent Error Messages
Create `lib/agent-errors.ts`:
- Map common Claude API errors to Spanish messages:
  - Rate limit → "El servicio de IA está temporalmente saturado. Reintenta en {seconds}s"
  - Timeout → "La generación tomó demasiado tiempo. Intenta con un prompt más corto"
  - Overloaded → "El servicio de IA está en mantenimiento. Reintenta en unos minutos"
  - Invalid key → "La API key de IA no es válida. Revisa la configuración"
  - Context too long → "El contenido es demasiado largo para procesar. Reduce el texto"
- Integrate into GenerateContentModal and action error handlers
