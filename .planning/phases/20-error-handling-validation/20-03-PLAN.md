# Plan 20-03: Toast Enhancement + Session Timeout

## Goal
Toast notifications have action buttons and persistent error display. Users get warned before session expiry with auto-save for drafts. Multi-tab logout syncs.

## Requirements
TOAST-01, TOAST-02, TOAST-03, TOAST-04, SESS-01, SESS-02, SESS-03

## Current State
- Custom Toast.tsx works well (4 types, 27 files use it)
- Success toasts auto-dismiss in 4s (close to target 3-5s) ✅
- Error toasts auto-dismiss too (should persist) ❌
- No action buttons on toasts ❌
- No session timeout logic ❌
- No auto-save ❌
- No multi-tab sync ❌

## Tasks

### Task 1: Enhance Toast System
Update `components/ui/Toast.tsx`:
- Add `action?: { label: string, onClick: () => void }` to Toast interface
- Add `persistent?: boolean` (no auto-dismiss) — default true for errors
- Update `error()` helper to set `persistent: true` by default
- Render action button in toast (e.g., "Reintentar", "Deshacer")
- Add `aria-live="polite"` for screen readers

### Task 2: Session Timeout Warning
Create `components/ui/SessionTimeout.tsx`:
- Track idle time via mouse/keyboard/touch events
- After 28 minutes idle → show warning modal with 2-minute countdown
- "Seguir trabajando" button resets the timer
- On expiry → redirect to sign-in page
- Add to LayoutShell.tsx

### Task 3: Auto-Save Drafts
Create `hooks/useAutoSave.ts`:
- Generic hook: `useAutoSave(key: string, data: T, saveFn: (data: T) => Promise<void>)`
- Debounced save (every 30 seconds if changed)
- Save on beforeunload event
- Save before session expiry (integrate with SessionTimeout)
- Visual indicator: "Guardado automáticamente" subtle text
- Integrate with EditContentModal and RichTextEditor

### Task 4: Multi-Tab Logout Sync
Create `hooks/useAuthSync.ts`:
- Listen to `storage` event for Clerk session changes
- On auth state change in another tab → show modal "Tu sesión se cerró en otra pestaña"
- Redirect to sign-in after 3 seconds
- Add to LayoutShell.tsx
