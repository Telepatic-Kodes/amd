1. Install Vitest and React Testing Library in the frontend:
```bash
cd ai-marketing-department/ai-marketing-department
npm install --save-dev vitest @testing-library/react @testing-library/jest-dom @testing-library/user-event @vitejs/plugin-react jsdom
```

NOTES on packages:
- `vitest`: Test runner (10-20x faster than Jest, native ESM + TS)
- `@testing-library/react`: Component rendering and queries
- `@testing-library/jest-dom`: Custom matchers (toBeInTheDocument, toBeVisible, etc.)
- `@testing-library/user-event`: Realistic user interaction simulation
- `@vitejs/plugin-react`: React plugin for Vite/Vitest (handles JSX transform)
- `jsdom`: Browser environment simulation for tests

2. Create `vitest.config.ts`:
```typescript
import { defineConfig } from 'vitest/config'
import react from '@vitejs/plugin-react'
import path from 'path'

export default defineConfig({
  plugins: [react()],
  test: {
    environment: 'jsdom',
    setupFiles: ['./vitest.setup.ts'],
    globals: true,
    css: false,
    include: ['**/__tests__/**/*.test.{ts,tsx}', '**/*.test.{ts,tsx}'],
    exclude: ['node_modules', '.next', 'remotion'],
    coverage: {
      provider: 'v8',
      include: ['app/**', 'components/**', 'lib/**'],
      exclude: ['node_modules', '.next', 'remotion', '**/*.d.ts'],
    },
  },
  resolve: {
    alias: {
      '@': path.resolve(__dirname, '.'),
      '@convex': path.resolve(__dirname, '../../convex'),
    },
  },
})
```

KEY DECISIONS:
- `globals: true` -- enables describe/it/expect without imports (matches Jest conventions)
- `css: false` -- skip CSS processing in tests (faster, not testing styles)
- Path aliases match tsconfig.json (`@/*` and `@convex/*`)
- Coverage targets app/, components/, lib/ (not remotion/)
