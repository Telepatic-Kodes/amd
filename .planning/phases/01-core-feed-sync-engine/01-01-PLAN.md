  <action>
Add three new tables to the existing schema in convex/schema.ts. Insert AFTER the auditLog table and BEFORE the closing of defineSchema.

**Table 1: feeds**
Purpose: Store configured RSS/Atom feeds to sync

Fields:
- `feedId: v.string()` - UUID identifier
- `url: v.string()` - Feed URL (unique)
- `name: v.string()` - Human-readable name
- `category: v.string()` - Category for filtering (e.g., "industry", "competitor", "technical")
- `status: v.union(v.literal("active"), v.literal("paused"), v.literal("error"))` - Current state
- `syncFrequency: v.union(v.literal("hourly"), v.literal("daily"), v.literal("weekly"))` - How often to sync
- `lastSyncAt: v.optional(v.number())` - Timestamp of last successful sync
- `consecutiveErrors: v.number()` - Error count for health tracking (SYNC-06)
- `lastErrorMessage: v.optional(v.string())` - Most recent error
- `createdAt: v.number()` - Creation timestamp
- `updatedAt: v.number()` - Last update timestamp

Indexes:
- `by_feedId: ["feedId"]`
- `by_url: ["url"]`
- `by_status: ["status"]`
- `by_category: ["category"]`

**Table 2: feedItems**
Purpose: Store individual feed entries with deduplication

Fields:
- `feedId: v.id("feeds")` - Reference to parent feed
- `contentHash: v.string()` - SHA-256 composite key for deduplication (SYNC-02)
- `guid: v.optional(v.string())` - Original GUID if present
- `title: v.string()` - Item title
- `link: v.string()` - Item URL
- `content: v.optional(v.string())` - Full content/description
- `summary: v.optional(v.string())` - Short summary (for truncated feeds)
- `author: v.optional(v.string())` - Author name if available
- `publishedAt: v.optional(v.number())` - Publication timestamp
- `categories: v.optional(v.array(v.string()))` - Item categories/tags
- `createdAt: v.number()` - When we stored it
- `updatedAt: v.number()` - Last update

Indexes:
- `by_contentHash: ["contentHash"]` - For deduplication lookups (STOR-05)
- `by_feedId: ["feedId"]`
- `by_feedId_publishedAt: ["feedId", "publishedAt"]` - For chronological queries
- `by_publishedAt: ["publishedAt"]` - For global timeline

**Table 3: feedSyncLog**
Purpose: Track sync execution history for debugging and health monitoring

Fields:
- `feedId: v.id("feeds")` - Reference to feed
- `syncedAt: v.number()` - Execution timestamp
- `status: v.union(v.literal("success"), v.literal("partial"), v.literal("failed"))` - Sync outcome
- `itemsFound: v.number()` - Total items in feed
- `itemsAdded: v.number()` - New items stored
- `itemsSkipped: v.number()` - Duplicates skipped
- `duration: v.number()` - Sync duration in ms
- `errorMessage: v.optional(v.string())` - Error details if failed

Indexes:
- `by_feedId: ["feedId"]`
- `by_syncedAt: ["syncedAt"]`
- `by_feedId_syncedAt: ["feedId", "syncedAt"]`

Follow existing schema patterns:
- Use defineTable() with v validators
- Include createdAt/updatedAt where appropriate
- Use v.id() for foreign key references
- Add comprehensive indexes for query patterns
