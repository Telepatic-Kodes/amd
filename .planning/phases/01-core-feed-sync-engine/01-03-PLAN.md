  <name>Task 1: Create fetchFeed action</name>
  <files>convex/feeds/fetchFeed.ts</files>
  <action>
Create the main sync action at `convex/feeds/fetchFeed.ts`.

This action fetches a single feed URL, parses it with Feedsmith, validates/normalizes items, and calls storeFeedItems mutation.

**Implementation:**

1. Export action `fetchFeed` with args:
   - `feedId: v.id("feeds")` - The feed to sync (lookup URL from DB)

2. Action flow:
   ```
   a. Query feed by ID to get URL and metadata
   b. If feed not found or paused, return early
   c. Fetch XML via native fetch() with timeout
   d. Parse with Feedsmith
   e. Validate and normalize each item
   f. Call storeFeedItems mutation with normalized items
   g. Update feed health based on result
   h. Return sync summary
   ```

3. Feedsmith usage:
   ```typescript
   import { parse } from 'feedsmith';

   // Parse supports RSS 2.0, Atom, RSS 1.0 (RDF) automatically
   const feed = await parse(xmlString);
   // feed.items contains array of entries
   ```

4. Error handling (SYNC-03):
   - Wrap fetch in try/catch with timeout (30 seconds)
   - Wrap parse in try/catch for malformed XML
   - If parse fails, log error but don't throw - return partial result
   - Track errors for health monitoring

5. HTTP fetch with timeout:
   ```typescript
   const controller = new AbortController();
   const timeout = setTimeout(() => controller.abort(), 30000);

   try {
     const response = await fetch(url, {
       signal: controller.signal,
       headers: { 'User-Agent': 'AMD-FeedSync/1.0' }
     });
     const xml = await response.text();
   } finally {
     clearTimeout(timeout);
   }
   ```

6. Process items:
   ```typescript
   const normalizedItems = [];
   const validationErrors = [];

   for (const item of feed.items) {
     const validation = validateFeedItem(item);
     if (validation.valid) {
       const normalized = normalizeFeedItem(item, feedUrl);
       const contentHash = await generateContentHash({
         feedUrl,
         guid: normalized.guid,
         link: normalized.link,
         pubDate: normalized.publishedAt?.toString(),
         title: normalized.title
       });
       normalizedItems.push({ ...normalized, contentHash });
     } else {
       validationErrors.push(validation.errors);
     }
   }
   ```

7. Call mutation to store:
   ```typescript
   const result = await ctx.runMutation(internal.feeds.storeFeedItems.storeFeedItems, {
     feedId,
     items: normalizedItems
   });
   ```

8. Return type:
   ```typescript
   {
     success: boolean;
     feedId: string;
     itemsFound: number;
     itemsAdded: number;
     itemsSkipped: number;
     validationErrors: number;
     duration: number;
     error?: string;
   }
   ```

**Export 1: storeFeedItems mutation**

Args:
- `feedId: v.id("feeds")`
- `items: v.array(v.object({...}))` - Array of normalized items with contentHash

Implementation:
1. For each item, check if contentHash exists in feedItems (STOR-05):
   ```typescript
   const existing = await ctx.db
     .query("feedItems")
     .withIndex("by_contentHash", q => q.eq("contentHash", item.contentHash))
     .first();
   ```

2. If not exists, insert into feedItems:
   ```typescript
   await ctx.db.insert("feedItems", {
     feedId,
     contentHash: item.contentHash,
     guid: item.guid,
     title: item.title,
     link: item.link,
     content: item.content,
     summary: item.summary,
     author: item.author,
     publishedAt: item.publishedAt,
     categories: item.categories,
     createdAt: Date.now(),
     updatedAt: Date.now()
   });
   ```

3. Track counts: itemsAdded, itemsSkipped

4. Return: `{ itemsAdded: number, itemsSkipped: number }`

**Export 2: updateFeedHealth mutation**

Args:
- `feedId: v.id("feeds")`
- `success: v.boolean()`
- `errorMessage: v.optional(v.string())`

Implementation:
```typescript
const feed = await ctx.db.get(feedId);
if (!feed) return;

if (success) {
  await ctx.db.patch(feedId, {
    lastSyncAt: Date.now(),
    consecutiveErrors: 0,
    lastErrorMessage: undefined,
    updatedAt: Date.now()
  });
} else {
  await ctx.db.patch(feedId, {
    consecutiveErrors: feed.consecutiveErrors + 1,
    lastErrorMessage: errorMessage,
    status: feed.consecutiveErrors >= 2 ? "error" : feed.status,
    updatedAt: Date.now()
  });
}
```

Note: After 3 consecutive errors, feed status becomes "error" (health tracking SYNC-06).

**Export 3: logSync mutation**
