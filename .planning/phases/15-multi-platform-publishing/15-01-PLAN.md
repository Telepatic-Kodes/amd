<task type="auto">
  <name>Task 2: Add Twitter and Instagram OAuth HTTP routes</name>
  <files>convex/http.ts</files>
  <action>
Add 4 new HTTP routes to http.ts, following the exact pattern of the existing /linkedin/auth and /linkedin/callback routes:

**GET /twitter/auth:**
- Read TWITTER_CLIENT_ID from process.env
- Build Twitter OAuth 2.0 authorization URL: https://twitter.com/i/oauth2/authorize
- Use PKCE flow (generate code_verifier and code_challenge with S256 method)
- Scopes: "tweet.read tweet.write users.read offline.access"
- Set state cookie `twitter_oauth_state` and PKCE verifier cookie `twitter_code_verifier` (HttpOnly, SameSite=Lax, Max-Age=600)
- Redirect to Twitter authorization URL

**GET /twitter/callback:**
- Read code and state from URL params
- Handle error cases (redirect to /settings with twitter=error)
- Call internal.twitter.actions.exchangeCodeForTokens with { code, redirectUri, codeVerifier }
- Redirect to /settings with twitter=connected&name={username} on success

**GET /instagram/auth:**
- Read META_APP_ID from process.env
- Build Facebook OAuth URL: https://www.facebook.com/v19.0/dialog/oauth
- Scopes: "instagram_basic,instagram_content_publish,pages_show_list,pages_read_engagement"
- Generate state, store in cookie `instagram_oauth_state`
- Redirect to Facebook authorization URL

**GET /instagram/callback:**
- Read code and state from URL params
- Handle error cases (redirect to /settings with instagram=error)
- Call internal.instagram.actions.exchangeCodeForTokens with { code, redirectUri }
- Redirect to /settings with instagram=connected&name={username} on success

IMPORTANT for Twitter PKCE: Twitter requires code_challenge_method=S256. Generate a random code_verifier (43-128 chars alphanumeric), compute SHA-256 hash, base64url encode it as code_challenge. Store code_verifier in an HttpOnly cookie so the callback can pass it to the token exchange.

IMPORTANT: The callback routes should try to read the state from cookies for CSRF validation but NOT fail if cookies are missing (some browsers block third-party cookies). Log a warning but proceed.
